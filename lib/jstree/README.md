# jsTree
jQuery 树形控件

## 简要介绍
基于 jQuery 的可交互树形组件，支持复选框、拖拽、右键菜单、主题皮肤等，常用于图层树、目录树场景。

## 相关地址
- 官网地址：https://www.jstree.com
- github地址：https://github.com/vakata/jstree

## 本地版本信息
3.3.7

## 本地文件说明
含 `themes/` 主题子目录。
目录内文件：`jstree.js`、`jstree.min.js`、`LICENSE`
