# Cesium
Web 三维 GIS 地图框架

## 简要介绍
面向三维地球和地图的世界级 JavaScript 开源产品，可零插件搭建虚拟地球 Web 应用，在性能、精度、渲染质量、多平台与易用性上有高质量保证；本目录为 Mars3D 配套定制构建版（含 `Mars3D/` 扩展目录）。

## 相关地址
- 官网地址：https://cesium.com/cesiumjs/
- github地址：https://github.com/CesiumGS/cesium
