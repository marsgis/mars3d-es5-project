# Bootstrap
Twitter 开源的前端 UI 框架

## 简要介绍
提供栅格系统、全局样式与常用 UI 组件；内含 Glyphicons Halflings 字体，并随目录收录 select/slider/table/checkbox 等 jQuery 扩展插件（见子目录）。

## 相关地址
- 官网地址：https://getbootstrap.com
- github地址：https://github.com/twbs/bootstrap

## 本地版本信息
3.3.7

## 本地文件说明
内含 `fonts/`（Glyphicons Halflings 字体）与 `bootstrap-select/`、`bootstrap-slider/`、`bootstrap-table/`、`bootstrap-checkbox/` 等子目录。
目录内文件：`bootstrap.css`、`bootstrap.js`、`bootstrap.min.js`、`LICENSE`
