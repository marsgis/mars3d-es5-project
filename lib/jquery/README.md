# jQuery
快速、小巧的 JavaScript 工具库

## 简要介绍
简化 HTML 文档遍历与操作、事件处理、动画与 Ajax；本目录另收录若干基于 jQuery 的插件（见子目录）。

## 相关地址
- 官网地址：https://jquery.com
- github地址：https://github.com/jquery/jquery

## 本地版本信息
2.1.4

## 本地文件说明
另含 `lazyload/`、`mCustomScrollbar/`、`minicolors/`、`scrollTo/`、`ztree/`、`jedate/` 等子目录（以各仓库收录为准）。
目录内文件：`jquery-2.1.4.js`、`jquery-2.1.4.min.js`、`LICENSE`
