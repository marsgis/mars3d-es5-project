# animate.css
跨浏览器 CSS3 动画库

## 简要介绍
提供大量预设 CSS3 动画类（进入/强调/退出），可配合任意前端框架使用。

## 相关地址
- 官网地址：https://animate.style
- github地址：https://github.com/daneden/animate.css
